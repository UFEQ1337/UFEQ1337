### 👋 About Me

I'm a **QA Automation Engineer** who lives in two worlds: classic **test automation** and modern **LLM evaluation**. I design end-to-end test frameworks and load tests, and I measure the quality of LLM/RAG systems with metric-driven, reproducible evaluation.

- 🧪 Building scalable **E2E & API automation** with **Playwright (TypeScript)** and Selenium
- ⚡ Running **performance & load tests** with **k6** and **Locust**
- 🧠 Evaluating **LLM / RAG pipelines** with **Ragas** in **Python** — faithfulness, answer relevancy, context precision/recall
- 🐍 Comfortable across **TypeScript** and **Python**, with **SQL** for data validation
- 🔧 Wiring quality gates straight into **CI/CD** (GitHub Actions, GitLab CI)
- 🎵 Currently building **[nyxio](https://github.com/UFEQ1337/nyxio)** — a Dockerized Discord music bot in Python
